## Wichtige Bug-Fixes in Session 017

### Fix 1: LangGraph Annotated-Reducer für paralleles Routing

**Problem:** `intent=both` crashte mit `InvalidUpdateError: Can receive only one value per step`.

**Ursache:** Alle Nodes gaben `{**state, ...}` zurück. Mit `Annotated`-Reducer werden alle Returns durch den Reducer geschickt — Akkumulation statt Überschreiben.

**Fix:**
- `SupervisorState` in [main_workflow.py](../main_workflow.py): `wiki_writes` und `telegram_messages` auf `Annotated[list, operator.add]`, `agent_outputs` auf `Annotated[dict, _merge_dicts]`
- Alle Nodes geben **nur geänderte Keys** zurück (kein `{**state}` mehr):
  - [agents/supervisor.py](../agents/supervisor.py): `classify` → `{"classified_intent": ...}`, `review` → `{"supervisor_verdict": ..., "review_notes": ...}`
  - [agents/graph_reader.py](../agents/graph_reader.py): `{"graph_context": ...}`
  - [agents/diary_agent.py](../agents/diary_agent.py): `{"agent_outputs": ..., "wiki_writes": ..., "telegram_messages": ...}` (kein State-Spread)
  - [agents/language_agent.py](../agents/language_agent.py): identisch
  - `write_node` + `index_node` in [main_workflow.py](../main_workflow.py): `{}`

### Fix 2: Dry-Run Monkey-Patch in test_ingest.py

**Problem:** Dry-Run schrieb tatsächlich Dateien — `execute_writes` wurde in `agents.graph_writer` gepatch, aber `main_workflow` hatte eine eigene Referenz.

**Fix:** [scripts/test_ingest.py](../scripts/test_ingest.py) patcht jetzt beide Referenzen: `_gw.execute_writes = _dry_execute` **und** `_mw.execute_writes = _dry_execute`.
