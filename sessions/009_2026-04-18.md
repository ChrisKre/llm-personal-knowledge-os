## Kernkonzepte

**Graph Context Match:** Vor jeder Agent-Ausführung: Top-N relevante Wiki-Seiten für den Input laden. Agenten bewerten nie isoliert. graph_reader v2 nutzt Tag-Overlap-Scoring für präzisere Resultate.

**Zwei State-Ebenen:**
- `user_profile.md` (~80-120 Zeilen) — immer im Kontext, statisch
- `graph_context` — dynamisch, per-Task, Top-N Wiki-Seiten

**WikiWrite-Vertrag:** Kein Agent schreibt direkt Dateien. Alle schreiben WikiWrite-Objekte → graph_writer führt nach Supervisor-Freigabe aus.

**Audio-API-Bug (V1):** Claude verarbeitet kein Audio. Story-Lab V1 gibt nur Timing-Feedback (Whisper) + Transkript-Strukturanalyse (Sonnet auf Text). Tonal-Qualität (Enthusiasmus, Natürlichkeit) erst wenn Audio-API existiert.
