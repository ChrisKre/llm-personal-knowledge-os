# Bridge: azafrán (es ↔ en)

## Type
cognate

## Key insight
Spanish azafrán and English saffron come from the same Arabic word, za'farān. Spanish took many food words directly from Arabic (azúcar, aceite, arroz), often keeping an initial a-, while English received them later via French or Latin.

## Contrast example
- **es:** Añade el azafrán al caldo.
- **en:** Add the saffron to the stock.
- *Same word, same spice — only the start changed.*
